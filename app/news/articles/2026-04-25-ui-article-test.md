## 1. テキスト装飾
通常のテキスト**太字（ボールド）**、*斜体（イタリック）*、***太字かつ斜体***。  
~~打ち消し線~~

> 引用はこのように表示されます。
> > ネストされた引用も可能です。

## 2. リスト表示
### 箇条書きリスト
* 項目 A
  * 子項目 A-1
  * 子項目 A-2
* 項目 B
* 項目 C

### 番号付きリスト
1. 第一ステップ
2. 第二ステップ
   1. サブステップ
   2. サブステップ
3. 第三ステップ

### チェックリスト（タスクリスト）
- [x] 完了したタスク
- [ ] 未完了のタスク
- [ ] これからやるタスク

## 3. コードと数式
### インラインコード
文章中に `const message = "Hello"` のようにコードを挿入できます。

### コードブロック
シンタックスハイライト（言語指定）が可能です。

```javascript
function greet(name) {
  console.log(`Hello, ${name}!`);
}
greet("World");
```

### 数式 (LaTeX)
インライン数式: $E = mc^2$

ディスプレイ数式:
$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$
